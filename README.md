# lightspeed.ff

[lightspeed.nvim](https://github.com/ggandor/lightspeed.nvim), but for FireFox

FireFox addon: [Install here](https://addons.mozilla.org/en-US/firefox/addon/lightspeed-ff/)

## Keys

| Key   | Action                                                 |
| ----- | ------------------------------------------------------ |
| `f`   | Label every interactable element; type a label to jump |
| `gg`  | Top of page                                            |
| `G`   | Bottom of page                                         |
| `Esc` | Leave jump mode                                        |
| `⌫`   | Un-type a label character                              |

Keys are ignored while typing in a text field.
