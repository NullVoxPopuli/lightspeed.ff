# 3.1.0

- `gg` / `G` scroll to the top / bottom of the page, as in vim
- a badge in the bottom-right corner names each command as it runs
  ("Jump", "Top of Page", "Bottom of Page")
- `f` no longer fires while typing in inputs inside shadow DOM, ARIA
  textboxes/comboboxes, or custom editors

# 3.0.0

- greatly slimmed down codebase
- even fewer permissions (absolute minimal)
- development can now happen without a build
  - "Load temporary extension" points at `src` folder
